# PL Semar TV Android

Aplikasi Android WebView untuk membuka:

https://plsemar.pages.dev

## Build APK online

1. Upload seluruh folder project ini ke repository GitHub.
2. Buka tab **Actions**.
3. Pilih **Build PL Semar TV APK**.
4. Jalankan **Run workflow**.
5. Setelah selesai, buka hasil workflow dan download artifact **PL-Semar-TV-APK**.
6. Ekstrak ZIP artifact untuk mendapatkan `app-debug.apk`.

APK debug dapat langsung dipasang di perangkat Android dengan mengizinkan instalasi dari sumber yang sesuai.
